🚀 Project Overview

A Python-based Expense Tracker designed to help users record, manage, and analyze their daily expenses. The application uses CSV/JSON files for data storage and provides an easy way to add expenses, view records, calculate total spending, and analyze expenses based on categories.

✨ Features
Add Expense: Add expense details such as date, category, description, and amount.
View Expenses: Display all recorded expenses in an organized format.
Update Expense: Modify existing expense information.
Delete Expense: Remove unwanted expense records.
Category Management: Organize expenses into categories such as Food, Travel, Shopping, Education, etc.
Total Expense Calculation: Automatically calculate the total amount spent.
Category-wise Analysis: Calculate spending for individual categories.
CSV/JSON Storage: Store and retrieve expense data using CSV or JSON files.

🛠️ Tech Stack
Programming Language: Python
Data Storage: CSV / JSON
Libraries: csv, json, datetime
Optional Library: Pandas
